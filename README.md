# 大肥鱼 · 鲸鱼娘桌宠

一个住在 Windows 桌面上的鲸鱼娘，会提醒你要做的事，也会时不时夸你两句。


## 直接使用

双击 `dist/大肥鱼.exe` 即可启动，不需要安装 Python。

> 单文件打包，首次启动约 2~3 秒（要解压 Qt 运行时），之后常驻内存约 80MB。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 双击她 | 打开任务清单 |
| 按住拖动 | 换个位置（会记住，拖丢了会自动贴回屏幕内） |
| 单击 | 随机说句话 / 夸你一句 |
| 右键 | 菜单：加任务、夸夸频率、大小、藏起来、关于、退出 |
| 托盘图标 | 单击唤出任务面板，右键同菜单 |

## 两个核心功能

**1. 任务提醒**

- 双击她 → 输入任务 → 选时间 → 「添加任务」
- 支持「只提醒一次」和「每天提醒」
- 快捷按钮：15 / 30 / 60 分钟后
- 到点前 5 分钟会先小声预告一次，到点时冒泡提醒 + 响一声 + 她开心地蹦一下
- 关掉软件期间错过的任务，下次启动会补提醒
- 任务面板里勾掉即完成（她会顺势夸你一句）

**2. 随机夸夸**

- 默认每 12 分钟左右主动夸一句，随机文案 30+ 条
- 右键 → 夸夸频率，可改为 5 / 10 / 15 / 30 分钟或关闭
- 菜单里也有「夸我一句」，想听随时点

## 数据存在哪

`C:\Users\<你的用户名>\.deepseek_pet\`

- `tasks.json`：任务清单
- `config.json`：位置、大小、夸夸频率、是否响铃
- `startup.log` / `error.log`：启动诊断与出错信息（一般不用管）

删掉这个文件夹等于恢复出厂设置。

## 一些小细节

- 她平时会自己呼吸、眨眼（三帧切换：待机 / 眨眼 / 开心）
- 说话和开心的时候会换成笑脸并轻轻蹦一蹦
- 屏幕上只允许有一只：重复双击 exe 会把已有那只叫出来，而不是再开一只
- 缩小到托盘后，从托盘图标或再双击 exe 都能叫回来

## 想改形象 / 二次开发

```
DeepSeekPet/
├── pet.py              # 主程序（PySide6，全部逻辑）
├── assets/pet/         # 三帧形象：idle / blink / happy（透明 PNG）
├── assets/icon.ico     # 应用图标
├── process_assets.py   # 抠图 + 对齐 + 缩放素材的脚本
├── make_icon.py        # 生成图标
├── test_logic.py       # 核心逻辑回归测试
└── test_ui.py          # UI 冒烟测试（截图）
```

换形象只需替换 `assets/pet/` 里的三张 PNG（保持尺寸比例一致，底部对齐），
然后 `python pet.py` 直接跑，或重新打包：

```
pyinstaller --noconfirm --onefile --windowed --name 大肥鱼 ^
  --icon assets/icon.ico --add-data "assets/pet;assets/pet" pet.py
```

环境依赖：`PySide6`（运行）、`pyinstaller`（打包）、`pillow + numpy + scipy`（仅素材处理需要）。

## 已知限制

- 只在 Windows 上验证过（用了 `Qt.Tool` 无边框透明窗 + 托盘）
- 三帧静态切换（眨眼 / 说话 / 开心），没有做骨骼动画
- 全屏游戏时她可能仍置顶，可从右键菜单「把鱼藏起来」
